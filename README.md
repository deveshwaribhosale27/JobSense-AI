# JobSense AI — Resume Analysis & Career Recommendation System

## Overview

JobSense AI is an AI-powered application designed to analyze resumes, compare candidate skills with job descriptions, identify skill gaps, and suggest relevant career paths.

## Features

* Resume PDF analysis
* ATS-style resume scoring
* Job description and skill matching
* Missing skill identification
* Career path recommendations
* Skill gap analysis

## Tech Stack

* Python
* Streamlit
* Resume PDF text extraction
* Machine Learning / NLP components used in the project

## Run Locally

1. Clone the repository.
2. Create and activate a Python virtual environment.
3. Install the required dependencies using `requirements.txt`.
4. Run the application:

```bash
streamlit run main.py
```

## Project Structure

* `main.py` — Main Streamlit application
* `app/` — Application modules
* `utils/` — Utility modules

## Limitations

ATS scores and career recommendations are estimates and should not be treated as guaranteed hiring outcomes.
